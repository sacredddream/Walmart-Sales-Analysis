# Walmart Sales & Inventory Analysis

This project provides a data-driven analysis of Walmart's sales performance and stock levels across the Quebec and Alberta regions using Power BI.

## 📁 Project Structure

* **`Walmart Sales Analysis.pbix`**: The core Power BI file containing data models, DAX measures, and interactive dashboards.
* **`dashboard/`**: Contains visual exports of the project:
* `Quebec Sales Analysis.png`: Regional sales breakdown and category performance.
* `Alberta Stock Analysis.png`: Inventory auditing and stock-to-profit metrics.
* `Map.png`: Geospatial distribution of retail locations.



## 📊 Dashboard Overviews

### 1. Sales Analysis (Quebec)

Focuses on revenue trends, monthly growth, and product category distribution.


### 2. Stock Auditing (Alberta)

Detailed inventory audit tracking item counts, stock availability, and regional profit margins.


### 3. Geographical Distribution

Visual representation of store density and performance across analyzed provinces.


## 🛠️ Technical Stack

* **Power BI Desktop**
* **DAX** (Custom measures for KPIs)
* **Power Query** (Data cleaning and transformation)

## 🚀 How to Use

1. Download the `Walmart Sales Analysis.pbix` file.
2. Open the file using **Power BI Desktop** to interact with the filters and visual elements.
